# ICSV Gestão

Sistema web para a Igreja de Cristo no Brasil, Campo San Vale. Preserve as regras confirmadas no roadmap e registre as decisões institucionais em aberto em PENDENCIAS_NEGOCIO.md.

- Trabalhe com autonomia dentro da tarefa. Consulte o usuário quando uma decisão institucional ou permissão impedir o trabalho e avance nas frentes independentes.
- Use os agentes especializados em `.codex/agents/` para tarefas independentes. Atribua áreas de edição distintas e integre as entregas antes de concluir.
- Preserve as chaves e relações dos cadastros centrais. Verifique escopo por congregação, autorização de escrita e origem dos IDs de relacionamento.
- Use somente dados fictícios em desenvolvimento e testes. Proteja credenciais e preserve dados existentes. Produção, dados reais e operações destrutivas exigem autorização explícita.
- Para concluir um módulo, exercite as operações e a persistência. Corrija falhas, reexecute as verificações e registre os resultados.
- Consulte o README para execução e a skill local `validar-modulo` para validação.
